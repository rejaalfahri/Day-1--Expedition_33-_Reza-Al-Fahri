Tujuan atau Kegunaan Repository
Repository merupakan tempat penyimpanan proyek yang digunakan untuk mengelola, menyimpan, dan melacak perubahan pada file atau kode program. Dalam penggunaan Git dan GitHub, repository memiliki beberapa kegunaan, yaitu:
- Menyimpan proyek: Menjadi tempat untuk menyimpan seluruh file proyek, seperti kode program, gambar, dan dokumen.
- Melacak perubahan: Mencatat setiap perubahan yang dilakukan pada file sehingga pengguna dapat mengetahui perkembangan proyek.
- Mengelola versi: Memungkinkan pengguna menyimpan beberapa versi proyek melalui proses commit.
- Mempermudah kolaborasi: Memungkinkan beberapa pengguna bekerja pada proyek yang sama melalui GitHub.
- Mengamankan dan mencadangkan proyek: Repository GitHub memungkinkan proyek disimpan secara online sehingga dapat diakses kembali dari perangkat lain.

Informasi Mengenai Kegiatan Workshop yang Didokumentasikan
Kegiatan workshop yang didokumentasikan mengangkat tema "Building with AI, Managing Change with GitHub". Workshop ini membahas pemanfaatan kecerdasan buatan (Artificial Intelligence/AI) dalam membantu proses pembuatan aplikasi serta penggunaan Git dan GitHub untuk mengelola perubahan dan perkembangan proyek.

Materi workshop meliputi pengenalan Prompt Engineering, cara membuat instruksi AI yang lebih spesifik, pengenalan Git dan GitHub, penggunaan repository, serta penerapan version control. Peserta juga diperkenalkan dengan beberapa perintah dasar Git, seperti git init, git add, git commit, git push, dan git pull.

Selain penyampaian materi, workshop juga mencakup praktik langsung pembuatan proyek sederhana berupa Student Task Planner. Dalam praktik tersebut, peserta diarahkan untuk menggunakan platform AI seperti Claude, Antigravity, atau ChatGPT untuk membantu membuat aplikasi, kemudian memasukkan proyek ke Git dan mengunggahnya ke GitHub. Peserta juga mempraktikkan proses melakukan perubahan pada proyek, kemudian menyimpan dan mengunggah kembali perubahan tersebut ke repository.

Secara keseluruhan, kegiatan workshop ini bertujuan memberikan pemahaman dan pengalaman praktis kepada peserta mengenai penggunaan AI dalam pengembangan aplikasi serta GitHub sebagai sarana penyimpanan, pengelolaan versi, dan kolaborasi proyek digital.
